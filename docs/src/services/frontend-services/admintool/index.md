# Admintool

Das Admintool unterstützt administrative Tätigkeiten zur Vorbereitung und Überwachung eines Wahltags.

## Wahltag Initialisieren

Im Bereich zur Initialisierung eines Wahltags können Wahltermindaten erstellt oder erneut erzeugt werden. Sobald Wahltermindaten für einen Wahltag vorhanden sind, können im selben Ablauf Wahllokalbenutzer erzeugt, exportiert und gelöscht werden.

Bereits vorhandene Wahllokalbenutzer werden beim Auswählen eines initialisierten Wahltags automatisch geladen und direkt in der Oberfläche angezeigt. Die Liste ist nach Benutzername sortiert, durchsuchbar und seitenweise mit 50 Einträgen pro Seite nutzbar.
